Checklist

  • Paste the denial reason verbatim. Arguing a reason they did not write wastes the appeal.
  • Policy page that actually covers this loss
  • A timeline: date of loss → FNOL → denial → this appeal
  • If health: include the member ID, date of service, CPT/HCPCS if you have them
  • If auto/home: photos before repairs, two estimates, police report number
  • Thirteen US states already limit AI-only medical denials. If a machine denied you, say so — and still attach the human file.
